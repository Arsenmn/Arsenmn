# Arsen Yergali

**Backend Developer · Node.js / NestJS · TypeScript**

I build the parts of a SaaS that nobody notices until they break: queues, background jobs, external integrations, payments, and the data paths that have to hold up under load.

---

### ⚙️ In production

Auto-repricing platform for **Kaspi.kz, Noon and Amazon** sellers: 140+ services, 90+ BullMQ queues, ~₸1B in daily seller GMV.

| | |
|---|---|
| 📈 **Autoscaling** | Workload-based scaling for price parsers (up to 73 pods), with faster VIP price updates and no extra infrastructure |
| 🧱 **Write path** | Thousands of single MongoDB updates replaced with a Redis buffer and batch flushing |
| 📉 **API cost** | Amazon SP-API calls cut **20x** via request batching and queue-level throttling |
| 💳 **Payments** | Freedom Pay with signed webhooks and idempotent callbacks, **~₸15M** processed in the first 3 months |
| ⚡ **Latency** | Report response **~3s → ~200ms** by moving heavy calculations to background jobs with Redis caching |
| 💬 **Integrations** | WhatsApp (WABA, WAHA, Wazzup) and an OpenAI support assistant with Whisper transcription and handoff to managers |

> Most of my commercial code lives in private repositories. I'm happy to walk through the architecture on a call.
